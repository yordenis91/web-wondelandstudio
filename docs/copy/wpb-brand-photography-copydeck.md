## 3. JSON-LD

Esta página introduce dos patrones nuevos frente a las de boda: **`Offer` recurrente**
con `priceSpecification` mensual, y **dos `OfferCatalog` en paralelo** (sesiones únicas
vs. partnership) en vez de un solo catálogo de tiers.

```json
{
  "@type": "Service",
  "@id": "https://wonderlandsstudio.com/west-palm-beach/brand-photography/#service",
  "name": "Brand Photography in West Palm Beach",
  "serviceType": "Branding Photography",
  "provider": { "@id": "https://wonderlandsstudio.com/west-palm-beach/#location" },
  "areaServed": { "@type": "AdministrativeArea", "name": "Palm Beach County, FL" },
  "hasOfferCatalog": [
    {
      "@type": "OfferCatalog",
      "name": "One-Time Sessions",
      "itemListElement": [
        {
          "@type": "Offer",
          "name": "Impulso Visual",
          "price": "700",
          "priceCurrency": "USD",
          "description": "Half-day branding session, up to 2 locations"
        },
        {
          "@type": "Offer",
          "name": "La Autoridad",
          "price": "3500",
          "priceCurrency": "USD",
          "description": "Full-day executive brand session, headshots and lifestyle"
        }
      ]
    },
    {
      "@type": "OfferCatalog",
      "name": "Monthly Content Partnership",
      "itemListElement": [
        {
          "@type": "Offer",
          "name": "Social Content",
          "priceSpecification": {
            "@type": "UnitPriceSpecification",
            "price": "500",
            "priceCurrency": "USD",
            "unitCode": "MON",
            "billingIncrement": 1
          }
        },
        {
          "@type": "Offer",
          "name": "El Socio de Crecimiento (photo-led)",
          "priceSpecification": {
            "@type": "UnitPriceSpecification",
            "price": "1500",
            "priceCurrency": "USD",
            "unitCode": "MON"
          }
        },
        {
          "@type": "Offer",
          "name": "Brand Partner (video-led)",
          "priceSpecification": {
            "@type": "UnitPriceSpecification",
            "price": "1350",
            "priceCurrency": "USD",
            "unitCode": "MON"
          }
        }
      ]
    }
  ]
}
```

`unitCode: "MON"` es el código UN/CEFACT para "mensual" — es lo que le indica a Google
que ese `Offer` es recurrente y no un pago único. Sin esto, un precio de $1,500 se lee
como sesión única y compite mal contra la de $700, en vez de comunicar valor mensual.

## 4. Lo que este deck le agrega al modelo de Sanity

Documentado explícitamente para el Bloque 2, así no se descubre a medio construir:

- **`servicePage.pageType`**: nuevo campo enum `'event' | 'subscription' | 'hub' | 'aggregate'`.
  Boda = `event`. Esta página = `subscription`. Determina qué componente de precios se
  renderiza (`PricingTable` de tiers fijos vs. el nuevo `SubscriptionTable` de dos columnas).
- **`pricingCatalog`** deja de ser un único array plano. Necesita un campo `billingType`
  (`oneTime` | `monthly`) por entrada, y un campo `track` opcional (`photo-led` | `video-led`)
  para las entradas que pertenecen a un catálogo paralelo en vez de una escalera de tiers.
- **Componente nuevo: `SubscriptionTable.astro`**, dos columnas en vez de filas de tier
  único. `PricingTable.astro` (el de boda) no sirve para esto sin forzarlo.
- **`schema.ts`** necesita una rama que genere `hasOfferCatalog` como **array** (boda es un
  solo catálogo, branding son dos en paralelo).
